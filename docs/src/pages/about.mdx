# Behind wp-react

Welcome! I'm **Farahmand Moslemi**, the creator and maintainer of `wp-react`. 

## The Motivation

As a developer who works heavily at the intersection of modern frontend frameworks and the WordPress ecosystem, I constantly ran into the same friction points: writing repetitive boilerplate for API calls, struggling with untyped REST responses, and managing complex authentication flows. 

I built `wp-react` to solve these problems. The goal was to create a developer experience that feels as native, fast, and type-safe as the React ecosystem itself, while fully embracing the power of the WordPress REST and GraphQL APIs.
